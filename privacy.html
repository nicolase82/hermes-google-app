Política de privacidad de Hermes

Última actualización: 16 de octubre de 2026

Hermes es un asistente personal de uso privado. Esta política explica qué datos de Google usa, cómo y con quién se comparten.

Datos a los que accede

Con la autorización explícita del propietario mediante OAuth de Google, Hermes puede acceder a:

  • Gmail: leer, enviar y etiquetar correos.
  • Google Calendar: ver y gestionar eventos.
  • Google Drive, Docs y Sheets: buscar, leer y editar archivos.
  • Contactos de Google: solo lectura.

Cómo se usan

Los datos se usan únicamente para atender las solicitudes que el propietario le hace a Hermes, por ejemplo resumir correos o consultar la agenda. Acciones como enviar correos, crear o borrar eventos y compartir archivos requieren su confirmación previa.

Almacenamiento

El token de acceso de Google se guarda solo en el computador del propietario. Hermes no mantiene servidores propios ni bases de datos con información de Google. Para generar respuestas, fragmentos del contenido pueden enviarse al proveedor de modelos de lenguaje que el propietario tenga configurado, en el momento de cada solicitud.

Compartición

Los datos de Google no se venden, no se usan para publicidad y no se comparten con terceros, salvo el procesamiento puntual descrito arriba.

Cumplimiento

El uso y la transferencia de la información recibida de las APIs de Google cumplen la Política de Datos del Usuario de los Servicios de las APIs de Google, incluidos sus requisitos de uso limitado.

Revocar el acceso

El acceso puede retirarse en cualquier momento desde myaccount.google.com/permissions. Al revocarlo, Hermes deja de poder acceder a los datos.
